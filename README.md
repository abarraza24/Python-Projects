# Python Projects

A collection of Python projects, practice exercises, and small applications I've built while learning and improving my Python skills.

This repository is organized by topic so I can keep smaller projects and exercises in one place while larger applications, like Digital Twin Nurse, stay in their own repositories.

## Repository Structure

- `fundamentals/` – Python basics, functions, loops, collections, and general practice
- `oop/` – Object-oriented programming projects and exercises
- `automation/` – Scripts for automating repetitive tasks
- `data-processing/` – CSV, JSON, data cleaning, and transformation projects
- `api-projects/` – Projects that work with REST APIs or web services
- `mini-projects/` – Small standalone Python applications and experiments

Larger portfolio projects are kept in separate repositories.
